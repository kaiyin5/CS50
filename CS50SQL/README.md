# CS50sql: Introduction to Databases with SQL

[CS50sql Official Website](https://cs50.harvard.edu/sql/)

## Content List
0. Querying - `SELECT`, `WHERE`, `LIKE`
1. Relating - `JOIN`, `INTERSECT/UNION`, `GROUP BY`
2. Designing - Table Constraints, Column Constraints, Altering Tables
3. Writing - CRUD of tables, `INSERT INTO`, `.import`
4. Viewing - Views, Common Table Expressions, Soft Deletions
5. Optimizing - Indexes, `EXPLAIN QUERY PLAN`, Covering Indexes, Transaction
6. Scaling - MySQL and PostgreSQL, Access Control: `GRANT`, `REVOKE`, SQL Injection Attacks
7. Final Project - Friend Matching Application DB by MySQL
